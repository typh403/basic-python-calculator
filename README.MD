# Basic Python Calculator

> *Note: This was one of my very first Python scripts built during my initial days of learning programming and exploring core logic.*

A simple, robust command-line calculator written in Python as part of foundational starter projects. Features basic error handling for invalid operations and division-by-zero prevention.

## Features
- Basic arithmetic operations (+, -, *, /)
- Input validation (`try-except` for numeric values)
- Division by zero safety check

## Usage
Run the script using Python:
```bash
python calculator.py
